# Namaa eYouth GTM classroom

Fictional children’s clothing demo for measurement lessons. No real orders, payments, enquiries or fulfilment.

- Full store: https://mmetwally23.github.io/namaa-gtm-classroom/
- Module 1: https://mmetwally23.github.io/namaa-gtm-classroom/module-1/collections/baby/
- Access instructions: https://mmetwally23.github.io/namaa-gtm-classroom/resources/

GitHub Pages serves main / (root). `.nojekyll` preserves the static build.
The full store and focused Module 1 exercise share the dedicated Namaa training container. Consent gates loading. GTM publication and GA4 destination receipt are separate checks; do not infer them from source configuration.

The instructor pages are public course tools. Their resets affect only the current browser’s demo storage. Never enter real customer or payment details.
Product and campaign imagery was generated for this fictional educational environment. The sample flower clip is CC0 (see the course asset provenance in the local project). This repository contains no credentials or private account screenshots.
